# HAIRATH ACADEMY Course Platform

## FINAL V15
- Node.js + Express + SQLite course platform
- Student/Admin login
- One free preview video per course for visitors
- Active students and admins can open all videos on YouTube
- Admin course/video management protected by management password `3833` by default
- Add/edit/delete courses and YouTube videos
- Lock/unlock videos
- Course thumbnail upload
- Female animated login character with normal, error and success/heart states
- Auto-refresh and fresh login form

## Start on Windows
Double-click `START-HAIRATH-ACADEMY.bat`.
Keep the command window open and use `http://localhost:3000`.

If Node.js packages are not installed, the launcher runs `npm install` automatically.
